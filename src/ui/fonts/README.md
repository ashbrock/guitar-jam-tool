| File | Family | Notes |
|---|---|---|
| `dm-sans.woff2` | DM Sans | Variable weight; we use Regular 400 and Medium 500 only. Latin subset from Google Fonts. |
| `noto-music-accidentals.woff2` | Noto Music | Only ♭ ♮ ♯ (U+266D–266F), which DM Sans doesn't have. Loaded via `unicode-range`. |
